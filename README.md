# Técnicas de asignación y administración de memoria

Simulador educativo en Python para el curso de Sistemas Operativos (UNSA).

## Requisitos y ejecución

Python 3.10 o superior.

```bash
python main.py
```

## Opciones

1. Simular particionamiento fijo y calcular la fragmentación interna.
2. Simular particionamiento variable y mostrar la memoria libre después de cada solicitud.
3. Comparar la asignación de procesos con First Fit, Best Fit, Worst Fit y Next Fit.
4. Analizar ejemplos de fragmentación interna y externa.

Elige `0` para salir del simulador.
